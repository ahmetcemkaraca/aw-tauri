# Contributing

Use a topic branch, preserve upstream licenses and add focused tests for changed
behavior. Describe checks that ran and any platform limitations in the review.
Build with the reviewed web interface revision described in [README.md](README.md).
Never attach real activity or credentials to issues or logs.

There is no verified PeakActivity security mailbox or support channel in this
component bootstrap. Do not forward fork-specific reports to upstream maintainers.
